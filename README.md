# Практическая работа №3 Инкапсуляция собственного класса

## Исправление ошибок

Ошибка 1: `public int Health { get; set; }`
Исправление: `public int Health { get; private set; }`
Проверка: При попытке изменить здоровье из `Program.cs` программа не скомпилировалась.

Ошибка 2: `value.Trim(); _name = value;`
Исправление: `_name = value.Trim();`
Проверка: Имя `"   Александр   "` вывелось без пробелов как `[Александр]`.

## Контрольные вопросы

Вопрос 1: Чем отличается запрет внешней записи от проверки допустимого числа?
Ответ: `private set` просто запрещает менять свойство снаружи, а сами числа проверяются внутри конструктора `Hero` и методов `TakeDamage()` и `Heal()`.

Вопрос 2: Как `Name = name;` связывает параметр конструктора, `value` и поле `_name`?
 Строка из `name` попадает в `value` внутри `set`, очищается от пробелов через `Trim()` и записывается в поле `_name`.

Вопрос 3: Какие значения показали, что правило `0 <= Health <= MaxHealth` соблюдается?
Ответ: При передаче `-100` получилось `0/100`, при `5000` получилось `200/200`, лечение на `5000` остановилось на `150`, а урон на `5000` остановился на `0`.

## Самостоятельный класс (`Product`)

Выбранное правило: Количество товара на складе (`StockQuantity`) не может быть меньше нуля.
Где проверяется: В конструкторе `Product` 
Результат при неправильном действии: При передаче `-5` в конструктор остаток стал `0`, а при попытке продать `50` штук при остатке `6` действие не выполнилось и остаток остался `6`.
